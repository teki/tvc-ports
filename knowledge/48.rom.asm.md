# ZX Spectrum 48K ROM Assembly

[48.rom.asm](48.rom.asm) is an annotated assembly listing for understanding
software calls into the standard 16 KiB Spectrum 48K ROM. It belongs in this
repository because it documents the Spectrum software environment rather than
the hardware implementation.

## Provenance

- Copied from `rtvc/data/48.rom.asm` during the initial repository split.
- Assembly file SHA-256:
  `aced13821606fa3389b1c159d66a6b8fc82f9862add32a3ffbac7aa7f801bcc5`
- Matching local `rtvc/roms/48.rom` SHA-256:
  `d55daa439b673b0e3f5897f99ac37ecb45f974d1862b4dadb85dec34af99cb42`
- The listing says it was last updated on 2004-12-13 and contains its original
  acknowledgements and credits.

The original ROM binary is not copied here. Its redistribution and acquisition
remain separate from the annotated listing.

## Regeneration and Verification

The current listing predates the `rtvc` disassembler workflow and is not
claimed to be generated byte-for-byte by it. Before replacing or mechanically
regenerating the listing:

1. identify its original upstream source and license;
2. assemble or otherwise compare all emitted ROM bytes against the recorded ROM
   hash;
3. preserve useful authored labels and functional comments; and
4. record the exact assembler/disassembler version and command.

Until then, treat this as a useful annotated reference with recorded byte-level
ROM identity, not as the canonical source for redistributing the ROM.
